# Maison catering

## Что это
Премиальный кейтеринг в Сочи: выездное обслуживание мероприятий и доставка сетов и боксов.
Одностраничный сайт показывает уровень работы, даёт порядок цен и приводит к заявке в мессенджер.

## Тип проекта
[ ] Концепт: только hero
[ ] Концепт: лендинг на 3–5 блоков
[x] Клиентский сайт

## Стек
Next.js App Router (статический экспорт), TypeScript, Tailwind v4, GSAP + ScrollTrigger, Lenis.
Three.js — нет: на сайте нет WebGL, все сцены — фотографии, типографика и трансформации.
Отклонений от базового стека нет. Вспомогательное: sharp — только в скрипте подготовки изображений
(`npm run images`), в браузер не попадает.

## Дизайн-система проекта
Шрифты:
- Заголовки: уточняется — выбор арт-директора по странице `/fonts`; до решения стоит лучший свободный вариант.
- Текст: уточняется — там же.
- Кириллица проверена по таблице cmap: уточняется (результаты проверки — на странице `/fonts`).

Цвета (других цветов в интерфейсе нет, цвет дают только фотографии):
- `--milk` — #FAF7F2 — фон страницы, текст на бордовом экране.
- `--bordo` — #5E1F2B — заголовки, кнопки, линии, экран заявки.
- `--ink` — #241C1C — основной текст; второстепенный — он же с прозрачностью (`--ink-2` 68 %, `--ink-3` 46 %).
- Линии: `--bordo` с прозрачностью (`--line` 28 %, `--line-soft` 14 %).

Сетка и ритм:
- 12 колонок на десктопе, 4 на мобильном; поля `--gutter`: 20px на 390, 2.5rem на десктопе.
- Корневой кегль на десктопе привязан к ширине окна (1920 → 16px, 2560 → ~21px, не меньше 15px):
  вся композиция пропорционально масштабируется между 1440 и 2560. На мобильном — 16px.
- Шаг отступов 8px (0.5rem). Между блоками — `--section` (clamp 96px…200px), внутри — кратно шагу.
- Кнопки и карточки прямоугольные, без скруглений. Скругления только у масок фотографий (арки, круги).

Движение:
- Easing по умолчанию — `expo.out` для появления, `power3.out` для откликов на курсор, `power2.inOut`
  для переходов между двумя состояниями. Линейных переходов нет, кроме scrub-анимаций, привязанных к скроллу.
- Длительности: заголовки построчно 1.1–1.3 с со сдвигом 0.08–0.1 с; текст и линии 0.8–1.0 с; отклик на курсор 0.5–0.7 с.
- Анимируются только `transform` и `opacity` (плюс `clip-path` для масок). Ширина/высота не анимируются.
- Привязка к скроллу: вращение тарелки, параллакс галереи. Плавная прокрутка — Lenis (на тач-устройствах — нативная).
- `prefers-reduced-motion`: вращение, параллакс и следование за курсором отключены, Lenis не запускается,
  содержимое сразу видно.

## Законы проекта
1. Три цвета: молочный, бордо, тёплый чёрный. Никаких других цветов, градиентов-украшений и теней, кроме тени под тарелкой.
2. Кнопки прямоугольные, без скруглений.
3. Весь текст — кириллицей. Латиница только в названии Maison catering и названиях мессенджеров (WhatsApp, MAX).
4. Все цены, составы, шаги, контакты и ссылки — в одном файле `src/data/site.ts`. В компонентах данных нет.
5. Сайт ничего не отправляет на сервер и ничего не хранит. Заявка — готовый текст, который человек сам отправляет в мессенджере.
6. С любого экрана до заявки — одно действие.
7. Видимые анимации неприкосновенны: скорость оптимизируем только путями, которые их не меняют.
8. `basePath` задаётся одной переменной в `site.config.mjs`. При переезде на maisoncatering.ru меняется только она (и `siteOrigin` там же).
9. Телефон везде кликабельный (`tel:`).
10. Красота, которая мешает понять и заказать, — брак.

## Планка качества
- PageSpeed 90+, включая мобильную версию
- 60 fps на всех анимациях
- prefers-reduced-motion учтён
- Проверено на 1920×1080, 2560×1440, 390×844

  это ~45 МБ стороннего кита. Список источников — в `skills-lock.json`.
- Рабочая ветка — `claude/friendly-pasteur-8o6sk1`; `main` — ветка по умолчанию, с неё публикуется Pages.
